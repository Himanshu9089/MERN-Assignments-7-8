# Assignment 8 – Responsive Audit

## Project
Grid Practice Pack

## Objective
Make the existing website responsive for mobile, tablet, and desktop screens.

## Breakpoints Used
- Desktop: Above 768px
- Tablet: 768px and below
- Mobile: 480px and below

## Screen Sizes Tested
| Device | Width |
|---|---:|
| Desktop | 1200px |
| Tablet | 768px |
| Mobile | 375px |

## Responsive Issues Checked and Fixed
1. Images overflowing the screen – Added max-width: 100%.
2. Horizontal scrolling – Added overflow-x: hidden.
3. Navigation links – Added flex-wrap for smaller screens.
4. Cards too narrow – Adjusted grid columns using media queries.
5. Buttons and links too close – Improved spacing and padding.

## Pages Tested
- Gallery
- Product Grid
- Dashboard

## Technologies Used
- HTML5
- CSS3
- CSS Media Queries
- CSS Grid

## Conclusion
The website was tested at desktop, tablet, and mobile screen sizes. Responsive CSS was added to improve layout, image sizing, navigation, and spacing.
